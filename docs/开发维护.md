# 开发维护手册

面向后续开发者和 AI。现行版本 1.8.0，schema 8。用户操作只有 README，功能计划只有 ROADMAP，历史变化只有 CHANGELOG；本文件不逐版叠加已废止规则。

## 运行与模块

教师机 Windows 10 x64，Python 3.11 / Flask / Waitress / SQLite 模块化单体。学生 Win7 Chrome/Firefox，ES5 / XHR，本地资源，不引入云部署或浏览器新语法。平台显示名称为智慧课堂综合平台，二进制、数据目录与仓库标识保留 ClassroomAssistant。

| 模块 | 数据与职责 | 边界 |
|---|---|---|
| core | 配置、事务、迁移、错误、启动权限 | 不含课堂业务 |
| classes | 稳定班级 id、name、year、semester、grade、deleted_at | 名称+年份+学期+毕业届数唯一，回收站也占用唯一键 |
| layouts | 不可变布局、跨班级设备状态/备注 | 设备不随班级切换 |
| students | 班级内稳定学生编号、规范姓名、私密备注 | 姓名不是主键，公开状态不等于备注 |
| seating | 当前座位、登记冲突、存档、纠正、长期换座写入 | 其他模块必须调用公共服务 |
| attendance | lessons、attendance_entries、attendance_leave、seat_change_requests | 课堂名单快照、签到、长期请假、审批和日志 |
| rollcall | 当前候选投影、瞬时点名；旧 rollcall_draws 兼容读取 | 无当前考勤就读固定座位，不创建课堂；新点名结果不持久化，rollcall_selections 每班覆盖最后手动范围 |
| exports | 原 Excel XML 指定单元格填值与版式保留 | 只调用座位公共读取接口 |
| web | 教师/学生投影、HTTP、页面、同源校验 | 页面不直接访问数据库 |

## 公共接口与数据归属

`seating.get_current_arrangement(connection=None)` 读取当前上课班级；`get_arrangement(class_id, round_id=None)` 读取指定班当前座位或历史存档。输出 class、round、layout、registrations、count、is_current、seat_configs、active_class_id。内部登记包含 id、student_id、name、seat_no、group、source_ip、student_note，不能原样返回给学生。

学生投影 `seating.active` 去除 IP、学生与设备备注，只留座位、姓名、设备是否可用和本人占位。设备设置始终反映当前物理设备；存档冻结学生备注，不随资料变化。

考勤 `current(db, arrangement)` 校验本地日期、当前班级和登记编号，`detail(lid, connection)` 返回课堂快照，`state(student,ip,client_id)` 作投影。学生公开六种考勤状态及指定重签标志；私密备注、审批原因、来源 IP 继续隐藏。long_leave 公开是用户在 1.5.0 明确授权的状态展示。

点名 `rollcall.current(connection=None)` 在同一读事务通过 seating、attendance 公共服务获得布局与候选。没有本节已发起签到的课堂，source=seating，context_id=seating:round_id；有则 source=attendance，context_id=attendance:lesson_id。签到关闭仍用到场名单，结束课堂后回到固定座位。客户端提交 context_id，过期上下文拒绝；服务端重新取候选，不相信客户端名单。

新 `draw_current` 使用 secrets.choice，在进程锁内保留上一次上下文和学生编号，候选>1 时排除紧邻上一人；单一候选必须允许并明确显示人数。不是整轮不重复算法。程序重启忘记上一次点名，结果不写库；旧 /rollcall/<lid> 保留 v1 兼容和旧历史表，不回删历史。新 UI 不使用旧写接口。

## 登记、签到与审批规则

- 写事务使用 BEGIN IMMEDIATE，WAL，超时 15 秒。座位、客户端、学生编号及 IP 键的唯一约束防覆盖。来源 IP 从 socket 读取，规范化 IPv4/IPv4-mapped IPv6，不信任转发头；模拟 IP 中间件仅在测试脚本。
- IP 限制以登记 id 为范围，无 10 分钟冷却。清除会释放当前占用；submissions 保存幂等收据，旧重试不会复活教师清除的数据。可在 settings.json 设置 limit_one_registration_per_ip=false，但会降低跨浏览器限制强度。
- 学生姓名 NFKC、去空白、casefold 后同名拒绝；教师 force_new 创建独立身份。同名不自动合并。座位弹窗可编辑学生备注，旧独立未就座入口已移除，底层已有资料/API 保留兼容。
- 发起新登记携带 expected_current_id，防止双击/陈旧页面连建存档；旧座位只读，新座位立即为空。classroom_state 保存当前班级，查看别班不自动 publish。
- 开始课堂先结束登记，取当前已就座学生快照；已有未结束课时拒绝重复开始。未开展考勤不自动记缺勤。日期变更、换班或新登记使旧课堂无法学生提交。
- open 设置默认 10 分钟、范围 1—40 的服务端截止。截止时刻起是 late，迟到秒数按 cutoff 算；到期不关闭、不把 pending 自动改 absent。教师 close/end 才关闭并把 pending 记缺勤。已关闭旧课不自动重开；无 deadline 的旧课保留 late_after 兼容阈值，新课无宽限输入。
- 一课每学生、IP、会话、座位只一条签到；相同提交不改变第一次时间。教师补签在 close 后可做，ended 后只读。首次到场写 first_signed_at，迟到以其计算；signed_at 为最新设备签到时间。mark pending 释放占用并授予 recheckin_allowed；close 后仅该 pending 学生可签到，成功或下课清零。教师同座纠正保留 IP/会话，新设备不猜 IP。
- 长期请假独立 attendance_leave 标记，下课不解除，后续课继续；成功签到解除。备注关键词不驱动状态。
- 临时换座只改考勤 seat_no。理由 device_fault 或 long_term；设备故障不自动停用。两类均建立 kind=temporary/long_term 的请求，签到先记实际位置，审批确认其类型；临时同意只标记本节申请，长期审批同一事务调用 seating.approve_move，要求当前登记、原位一致、目标设备可用且无固定占位。不删除他人、不修改历史快照；拒绝保留临时签到，纠正取消待审批请求。结束课堂前处理申请。

## HTTP v1

教师接口统一 /api/v1/teacher；本机 remote address 和 loopback Host、管理 cookie 必须同时通过。写操作要求 JSON、Origin 同源与 X-CSRF-Token。学生接口也限制同源，不允许网页跨域提交。错误结构 `{"error":{"code":"...","message":"中文提示"}}`，409 冲突、403 权限、400 参数、404 不存在、413 超限、503 DB 暂不可用。

| 接口 | 作用 |
|---|---|
| GET/POST /classes | 列班/新建 name、year、semester、可选 graduation_year（1900—2200或0未设置）；旧grade仅兼容；year 2000—2100，UI 当前年前后十年；省略二者兼容旧客户端 |
| POST /classes/manage | ids、action delete/restore；通过各模块 retire_classes 同事务结束活动 |
| GET /lessons/running；POST /classes/<id>/publish | 教师查询未下课课堂；切班携带 expected_lesson_id 确认结束该课，陈旧确认409 |
| GET/POST /classes/<id>/rounds | 座位与存档/新登记 expected_current_id |
| POST /rounds/<id>/close | 结束登记 |
| GET /current、/classes/<id>/arrangement | 当前上课座位/指定班，后者可带 round_id |
| PUT /rounds/<id>/seats/<number> | 教师纠正、学生关联、私密备注 |
| PUT /layouts/<id>/seats/<number>/config | disabled、note |
| GET/POST /classes/<id>/students；PUT /students/<id>/note | 兼容学生记录管理 API；新 UI 只在座位弹窗备注 |
| GET /classes/<id>/export | 原 Excel，可选 round_id |
| GET/POST /lessons；GET /lessons/current、/lessons/<id> | 课堂历史/新课/详情 |
| POST /lessons/<id>/open、close、end | 签到时长 duration_minutes / 结束签到 / 结束课 |
| PUT /lessons/<lid>/students/<sid> | present + seat_no 补签；或 pending/leave/absent/long_leave |
| POST /seat-changes/<id> | approve 布尔值 |
| GET /lessons/<id>/export | UTF-8 BOM CSV，转义公式前缀 |
| GET/POST /rollcall/current | scope=all/late/manual；候选状态 / context_id 瞬时抽取（结果不落库） |
| PUT /rollcall/selection | context_id、student_ids，校验本班名单后覆盖最后范围 |
| PUT /classes/<id>/grade | 年级补填，最多20字，不追改课堂快照 |
| GET /lessons/<id>/events | 教师读取该课签到/纠正设备记录 |
| GET/POST /rollcall/<lid> | 旧版兼容历史/抽取接口，新 UI 不调用 |
| GET /info | 版本、地址、数据目录等本机信息 |

学生 /api/v1/student/state，POST /registrations（round_id、seat_no、name、request_id）；GET/POST /attendance（lesson_id、name、seat_no、move_reason）。保留旧 student_id 兼容，但服务端必须核对属于本节名单。

## 页面与设计维护

student-rollcall.js轮询仅本人5秒内点名消息，网页内全屏提示5秒；app.js 处理选座；modules.js 管理考勤、点名、班级管理；logs.js 独立负责只读课堂查询和教学日志预留；seat-map.js 是稳定节点渲染器，只在 layout id 变化时重建。轮询不得重建输入框；学生考勤页发现登记开放自动 replace('/')，登记结束返回 /attendance。

统一 app.css：16px 正文、15px常规字重姓名、12px 状态；绿色已登记及正常/迟到已签到，蓝灰未到，白色空位，浅红缺勤/关闭/断线，灰色换座/设备停用，黄色请假。教师与学生状态共用连接状态的柔和样式。教师点击座位打开纠正弹窗，空位可选择本节学生补签；小屏侧栏回流，大屏右侧 sticky，避免遮盖座位。四字姓名按 1920×1080 主使用环境核对；手机保留横向座位图滚动。

## 模板与导出

resources 是初始文件；运行配置在数据目录 config。当前 classroom-64-v2，历史 v1 保留。原装 JSON 按解析内容等价判断（忽略 CRLF、BOM、键顺序），xlsx 按原文件 hash 判断；三份均为原装时保留旧配置后升级。真实自定义不覆盖。v1/v2 设备映射同一物理机房，当前登记升级布局，存档保持历史版本。

导出只改 Open XML ZIP 中指定工作表单元格，其他成员内容保留；姓名 inlineStr，未登记留空，原文件不覆盖。新模板人数格 E18，64 姓名格由配置核对座位数字。实际 Excel/WPS 打印仍需现场验证。

## 数据、迁移与回退

默认 %LOCALAPPDATA%\ClassroomAssistant；--data-dir 或 CLASSROOM_DATA_DIR 改路径。classroom.sqlite3 保存所有课堂数据；settings.json 设置端口与 IP 限制，session.key 是本机密钥，application.log 是轮转错误日志。不能上传这些运行数据。

迁移 1—8 已发布，不修改；新增结构从 9 开始。schema 5 班级复制重建保留 id 与关联，迁移连接外键关闭，业务连接开启，测试 foreign_key_check。目标 schema 2 跳过备份只属于用户旧测试库例外，以后恢复自动 SQLite backup。版本较新数据库拒绝旧程序；回退先恢复升级前完整备份。

运行中 WAL 可能有最新数据，不单独复制主文件、不删除 WAL/SHM；关闭后复制整个数据目录或使用 SQLite backup API。可用 DB Browser 只读看副本，不直接修改正式库绕过业务规则。

## Schema 6 与后续课堂数据

- lessons 增加 grade/year/semester 快照；已有 started_at/ended_at 为课堂时间边界，class_id/lesson_id 稳定。日志页面按班级资料筛选班，再选择具体课堂；改班级年级不改已存快照。
- attendance_entries 增加 recheckin_allowed 和 first_signed_at；教师 detail 包含当前 source_ip，学生投影去除 IP/时间事件。teacher 标记未签到是显式重签授权，截止后的其他学生不得借此提交；require_current 仍要求当前课堂未结束、同日、同班/登记。
- attendance_events 记录成功签到、教师补签、状态纠正时的设备座位和 IP。撤销前记录旧设备，重签写新设备；不是完整管理审计（无操作者身份/审批逐次历史）。升级前旧事件不伪造，原 source_ip 保留。
- seat_change_requests.kind 默认 long_term，旧申请保持原意。使用显式插入列；新临时请求默认 temporary。每生每课仍只有最后一次申请，旧申请可被后续申请覆盖；需要完整申请历史时另行递增迁移。
- rollcall_selections 按 class_id 保存 JSON 稳定学生编号数组。抽取在服务器按 scope 与当前有效候选取交集，manual 不绕过到场过滤；前端轮询不得覆盖未完成的提交。
- 教学日志仅预留同一课堂/学生的座位入口，没有采集其他内容。后续 AI 等模块以 lesson_id/student_id/实际设备关联，调用业务接口，不跨模块改表。

打包仅纳入正式Markdown/HTML文档与PNG/SVG图，排除用户临时文本；不得将docs下个人记录混入源码包或便携包。浏览器与便携包测试至少50人，服务并发测试另验证64选座客户端。

座位整体使用状态底色；竖线上下各留5px空白，未签到使用浅蓝灰色（#eaf0f5）。


## Schema 7、届数与导出

classes增加graduation_year，唯一键改为name/year/semester/graduation_year。固定毕业年份不随当前日期推算；旧grade保留兼容但不再在UI录入。旧数据届数=0，不猜测；lessons新增毕业届数快照。PUT /classes/<id>/graduation校验整数（0或1900—2200）。

GET /classes/export-csv?ids=班级id逗号列表：ClassCsvExport在一个只读事务调用各模块export_data；包含原始关联ID、私密备注与设备参考，CSV公式前缀转义、UTF8 BOM。不是备份恢复格式，不包含运行密钥/日志/设置或Excel文件。权限同教师接口；回收站班级也可导出。

点名动画前洗牌，按整数座位坐标逐个框选全部候选，最后POST /rollcall/current携带candidate_ids；服务端重新验证集合一致，防动画中名单变化而选到没跳选的人。结果暂存内存5秒用于通知；GET /student/rollcall只按当前课堂签到身份或当前登记IP/会话返回被选学生自己的通知。换课堂失效、到期消失，重启不恢复通知；sessionStorage记最后通知防页面刷新重复弹窗。不调用浏览器全屏权限，只覆盖网页视口。

长期审批仍在同事务更新固定座位+请求状态，更新后校验座位并回读返回registration与fixed_updated。教师界面成功后提供当前班链接；选座页重新聚焦时刷新。审批请求不可覆盖别人固定座位，存档不被改写。

用户仅授权本次清空旧测试数据；实际试运行之后数据需保留，不能设置启动自动清空或关闭备份。2026-09-09的默认旧库文件删除遭工具自动审批拒绝，数据库未删除；需要用户手动处理，不能在文档中写成已清空。


## 职务与课堂切换（1.8.0）

student_roles 归 students 模块，role 位标记：0无、1班长、2课代表、3兼任；不是私密备注。correct 接口可选整数 role，仅教师可写，遗漏时保留原标记；学生登记不会改变职务。当前登记经学生服务读取标记，存档时写入 registrations.role；课堂开始及结束时保存 attendance_entries.role 快照，正在上课时展示最新标记，下课后只读快照。CSV学生资料的role为当前职务，存档/已结束考勤的role为历史快照。旧数据默认0，不从备注猜测。

AttendanceService.publish_class 统一事务：校验 expected_lesson_id → 结束未下课课堂并冻结职务 → 调用 seating.publish_class(connection)。班级无效或登记冲突时全部回滚。open_registration 也在事务中拒绝上课中创建新登记；seating 内部接口保留兼容，不应由新HTTP模块绕过课堂协调入口。start 拒绝任何未结束课；过期日期的未下课记录允许教师明确结束，不能重新接受学生签到。

README直接引用 docs/images/architecture.png；可维护SVG和 scripts/render_architecture.py，发布时同步图片。点名动画约1800/人数毫秒一跳，局域网总时长验收3秒内；响应超时保持既有错误处理。角色角标7px不受正文最小字号约束，其余姓名15px、状态12px不变。
