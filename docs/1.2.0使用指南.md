# 1.2.0 上课操作

## 升级

关闭旧程序，解压新版便携包，运行其中的 ClassroomAssistant.exe。默认仍读取原用户数据目录，数据库升级到 schema 3 前会自动备份。不要把旧程序覆盖到正在运行的目录，不要删除原数据目录。

原装模板自动更新为 2026-09-07 新模板：当前安排保留姓名，改为每组四人；旧存档保留旧布局与旧版导出。自定义过数据目录 config 内模板/布局的安装不会自动覆盖，需维护者按开发说明检查后迁移。启动窗口“打开数据目录”可找到配置，不要只修改源码 resources 后期待运行中的旧 EXE 自动变化。

## 在线选座

先选择班级，再点“设为当前上课班级”；大标题显示实际学生端使用的班级。查看其他班级或历史存档不会切换上课班级。已有座位名单可以继续沿用，不必每节课重新登记。

## 考勤签到

1. 结束座位登记。打开“考勤签到”，点击“开始新的一节课”。每节课都执行一次，避免沿用上一节签到。迟到宽限默认 5 分钟，可设 0—40 分钟。
2. 点“发起签到”。学生从原网址顶部进入考勤，也可由极域打开 `http://教师机局域网IP:8765/attendance`。
3. 学生选择已有姓名和实际座位。所有设备可用且尚无人签到的座位均可选，原座位表中的姓名不占用本次签到座位；临时换座不会修改原安排。
4. 教师实时查看应到、实到、未签到、迟到等数据，点击学生行的“纠正 / 补签”设置请假、缺勤、长期请假或补签到场。
5. 长期请假在新课堂名单仍包含该学生时继续保留；该学生再次签到或教师补签到场后恢复正常，旧日志保持原状态。同名学生由教师补签。
6. “结束签到”停止学生提交，剩余未签到记为缺勤，教师仍可纠正。核对完成后“结束本节课”，转为只读日志。开始下一节也会结束上一节。

迟到时长 = 签到时间 −（发起签到时间 + 宽限分钟），不足 0 按 0；不是座位登记时间。教师补签按补签时刻计算。应到包含名单中的请假学生；实到为已到和迟到。没有发起签到的课堂不会被认定为全班缺勤。

按班级和本机日期查询历史课堂；CSV 可用 Excel/WPS 打开，含班级、课堂时间、学生编号、原座位、实际座位、状态、签到时间和迟到秒数。导出时间保存 ISO 时区标识；网页按教师机本地时间展示。历史记录只读，课堂结束前完成核对。

## 随机点名

在本节课堂打开“随机点名”，点击抽取。未发起签到时，从本节课开始时保存的座位名单抽取；已发起签到时，只从已到和迟到名单抽取，无人签到就不抽。抽取有姓名滚动动画，服务器保存结果；每次独立随机，可能重复。

## 班级数据管理

“班级数据管理”中勾选一个或多个班级，删除后进入回收站，保留座位、学生、考勤与点名记录，可恢复。删除正在上课的班级会结束相关登记和课堂，学生端不再显示该班。设备配置不变。

新学期班级建议加学期前缀，例如“2026秋 · 高一（1）班”。同名班级在回收站中也不会被覆盖。此版本未提供永久销毁历史数据的按钮；回收站用于整理班级，并不释放全部数据库空间。
