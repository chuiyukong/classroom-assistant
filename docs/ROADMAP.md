# 路线图与后续优化

更新：2026-09-08。当前 1.5.0；以下仅为未实现的后续方案，不代表已授权开工。优先：机房复测 → AI 课堂对话采集 → 考勤/点名完善 → 噪声提示 → 互动挑战。

## 最高优先：AI 课堂对话采集（未实现）

仅规划，未保存 API Key、未调用付费服务。此模块需要课堂和签到身份，与独立的随机点名不同。

### 可行性与范围

同一教师账号的 API 可以供多台学生机使用。学生机请求教师机，由教师机使用密钥调用 DeepSeek；密钥永远不发给学生，不写入网页、日志、GitHub 或下载包。并发限制按账号计算，多个 Key 不会增加账号总额度。开工前须重新核对账号并发能力、模型配额与网络，不承诺 64 人同时满速生成。

依据：[DeepSeek 限速与隔离](https://api-docs.deepseek.com/quick_start/rate_limit)、[模型与价格](https://api-docs.deepseek.com/quick_start/pricing)。开工时再次核对模型、价格和并发说明，不将今天的数值固化进程序。

采集范围仅限学生在本平台发送的提示词与收到的 AI 回复。无法采集他们另开网页、其他应用中的对话。无需监控屏幕或读取其他浏览器数据。

### 学生与教师流程

1. 教师开始本节课，开启“AI 学习”，设置任务名称、模型、每人请求次数、输入长度、最大输出长度和本节总预算。教师在本机设置页填写 Key，默认禁用，测试成功后显式开放。
2. 学生完成本节签到，以服务端签到身份关联课堂、学生编号和实际座位。重名由教师处理，不能仅依赖自填姓名。身份绑定不是实名认证，仍需要教师现场核对。
3. 页面明确说明：在此页面提交的提示词和 AI 回复会保存供教师教学分析；提示词将发送给 DeepSeek，请勿填写私密信息。发送给供应商的身份字段使用随机编号，不附带真实姓名、班级、请假备注。
4. 学生输入提示词，显示排队、生成中、完成、失败状态。回复逐步出现，可停止。断线后凭服务端生成任务编号重新获取已生成内容，不重新调用模型、不重复收费。
5. 教师按课堂、学生、座位查看对话、请求次数、输入输出字数和 Token 用量；可按日期查询并导出。首版只做客观统计，不自动判断学生能力、不自动给纪律分。
6. 教师结束任务后禁止新请求；在途任务可停止或有界完成。定义保留期限和按课堂删除记录的操作，删除前清晰显示范围。

### 技术组织

- `ai_learning` 模块保存任务、会话、消息与用量，读取课堂/考勤公共接口；不读取或修改座位内部表。
- 教师机单独的有界工作队列调用 DeepSeek SSE 流。首版建议默认 8 个工作请求、64 个排队位置，教师按实测调整；一个学生最多一个在途请求。禁止让几十条供应商长连接占住 Waitress 所有网页线程。
- 学生端保留 ES5 与 XHR。优先使用短轮询读取增量文本（约 300—500ms，可调），实现逐步显示；服务端对供应商使用真正的流式请求。若改用浏览器 SSE，必须验证旧版 Chrome/Firefox、断线重连及每浏览器连接上限。
- 增量按批次持久化，避免每个字都写 SQLite；读取游标只能访问自己的任务。断线不重新触发生成；程序重启将未完成任务标为“中断”，保留已有文本，不自动重放付费请求。
- 处理 401、429、余额不足、超时、断流、空增量和 SSE keep-alive。已开始输出的任务不自动重试；未开始输出的限流只允许有限退避，防止放大请求或重复计费。
- 预算按输入估算和最大输出预留，再用供应商返回用量结算；费用估算需标注价格版本，余额不足立即停止新任务。提供每生与全班总量双重限制。
- API Key 使用 Windows 用户范围的安全存储或 DPAPI；配置接口只返回“已设置”，不返回原文。导出排除密钥和内部错误响应。
- 教师查看任意对话仍沿用本机、管理会话、同源和 CSRF 校验；学生查询强制验证签名会话和任务归属。

### 建议数据库与接口

独立表：ai_activities（课堂任务/限制快照）、ai_conversations（学生关联）、ai_jobs（幂等键/排队/运行状态）、ai_messages（角色/文本）、ai_usage（模型/Token/费用估计）。新增迁移，升级前备份。

学生：创建消息任务、查询自身任务增量、停止自身任务、读取自身会话。教师：设置密钥、开启/结束活动、查看汇总、查询/导出/删除课堂对话。供应商响应中的文本按纯文本渲染，不能执行 HTML；如加入 Markdown，必须使用本地打包且经过审查的净化库。

### 交付前验收

模拟 64 人同时提交、排队公平性、教师操作仍能及时响应、学生之间无法读取对话、断线续显、超时/429、密钥不出现在日志或前端、单生和全班预算、停止/结束课堂、重启恢复、中文流式边界。供应商集成先用假流服务测试，再使用教师提供的 Key 做小额实测，最后在机房验证；未实测前不能宣传全班稳定可用。


## 考勤与点名后续优化

- 旧班级年份/学期补录与编辑（当前旧班仍标未设置），跨学期历史检索中同名班级的辅助区分。

- 考勤批量标记、纠正原因与完整审计链、学号/名册导入、学期汇总、Excel 原生考勤表；目前 CSV 日志已可查询导出。
- 点名按组、抽取不重复、公平轮换、多人数与历史检索页面；当前新点名结果不保存，仅避免紧邻重复；旧版记录保留。
- 受控机号绑定可加强防代签，IP 不能代替学生身份。长期请假已有显式状态，不依赖备注关键词。
- 回收站支持永久清理前的具体范围预览与备份，避免误删一个学期数据；当前只支持可恢复删除。
- 课堂数据共享使用服务接口和稳定学生 id，各模块独立保存结果，不通过 Excel 交换数据。

## 3. 教室噪声提示（中优先，需要实机麦克风验证）

- 使用教师机上实际带麦克风的耳机或独立麦克风；只有播放功能的耳机无法采集。先提供设备选择、输入电平测试、安静基线校准和手动开始/停止。
- 建议先在教师本机浏览器通过 getUserMedia + Web Audio 分析振幅，无需在 Win7 学生机采音。教师页的 localhost 地址满足浏览器本地可信来源条件；需要明确授权麦克风。[MDN 安全上下文](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts)、[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
- 用短窗 RMS、平滑电平和持续超阈时间触发，避免一次咳嗽就报警。普通麦克风未校准时显示“相对音量”或 dBFS，不宣称测得准确的环境声压级 dB SPL。[MDN 时域音频数据](https://developer.mozilla.org/en-US/docs/Web/API/AnalyserNode/getFloatTimeDomainData)
- 教师可选界面警示、短提示音或两者；建议持续 2—3 秒超阈才提醒，冷却 15—30 秒，可暂停讲课/播放视频期间提醒。具体默认值需实机试测后确定。
- 提示音播放期间暂停判定，避免自己的声音反复触发。根据教师讲解/小组讨论设置不同阈值，而不是全课要求一个阈值。
- 默认只在内存处理电平，不保存原始录音、不识别说话人、不上传音频。需要历史时只保存时间与电平统计。
- 验收：不同麦克风增益、无设备/被占用/拒绝权限、拔插、静音、提示音回灌、浏览器后台降频。噪声电平不能识别是教师讲课还是学生讲话。

## 4. 互动小游戏 / 课堂挑战（中后期）

建议定位为短时“课堂挑战”，可用于提神或纪律提醒后的复盘。提供跳过/替代题、不公开羞辱和不限体力的设计；不将高难游戏输赢直接计入惩罚分。

| 候选 | 玩法与难度 | 教学结合 |
|---|---|---|
| 算法迷宫 | 用有限指令走出迷宫；提高版限制步数或加入循环 | 顺序、分支、循环 |
| 二进制解码 | 30—60 秒将数字/颜色编码还原；分多档 | 信息编码 |
| 找 Bug 接力 | 找出短程序中的逻辑错误，先解释再运行 | 调试和表达 |
| Stroop 颜色挑战 | 按文字颜色而非字义作答；可放慢或换非色觉题 | 注意力切换 |
| 逻辑锁与数独片段 | 小规模逻辑推断，多步条件逐渐增加 | 推理与策略 |
| 小组协作拼图 | 每台机只有部分线索，口头协作完成 | 合作与信息整合 |

默认每局 1—3 分钟、教师一键结束、可调难度和减少动画/静音。服务器保存结果，客户端不自行提交可信得分；失败、断线和重复提交有明确处理。小游戏框架不应耦合考勤或座位写入。

## 5. 其他值得考虑的功能

| 建议 | 具体用途 | 建议优先级 |
|---|---|---|
| 学生举手 / 求助队列 | 点击座位发出求助，教师按等待时间处理，不必满教室喊老师 | 高 |
| 课堂计时与阶段提醒 | 操作练习、讨论、展示共用倒计时，教师暂停或延长 | 高 |
| 一题快答 / 理解度投票 | 学生选“会了/需要帮助”或答一题，教师在座位图看分布 | 高 |
| 离堂反馈 | 下课前一句收获、一个问题，保留到班级教学记录 | 中 |
| 设备报修闭环 | 学生报告故障，教师确认后变停用，记录维修与恢复时间 | 中 |
| 分组与角色轮换 | 按既有小组分配组长、记录员、汇报人，避免总由同一人承担 | 中 |
| 任务完成进度 | 学生报告进度卡点，教师快速定位需要支持的座位 | 中 |
| 课堂资源入口 | 集中展示本课链接、材料和提交地址，减少手输网址 | 中 |
| 班级课后概览 | 汇总签到、帮助请求、任务完成和反馈，避免只用纪律数据评价学生 | 后期 |

极域已有广播、远程控制、文件分发功能，暂不重复开发这些重型能力。先围绕座位名单提供轻量辅助。

每个模块先写清：课堂触发方式、使用者、数据归属、是否显示学生姓名、完成与取消行为、重复请求和断线行为、实际机房验收方法。经用户明确选择后再安排版本，不按本文自动开工。
