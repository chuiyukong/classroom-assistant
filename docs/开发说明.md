## 1.4.0 当前规则（覆盖下方历史时限说明）

schema 5：保留迁移 1—4，新增 classes.year/semester，唯一约束为 name/year/semester。迁移通过新表复制全部班级、保留 id 后替换原表；迁移专用连接外键关闭，正常业务连接始终开启，测试以 foreign_key_check 核对关联。旧班 year=0、semester='' 表示未设置，不推断学期，不改名；暂无旧班补录界面。新建 API POST /teacher/classes 接受 year 整数 2000—2100、semester 上学期/下学期，旧客户端同时省略时兼容。

签到截止不再关闭课堂：删除 expire_due/_expire 自动写关闭时间。checkin 在事务中比较服务端当前时间与 attendance_deadline，恰好截止也计 late（秒数可为 0），其后记实际迟到秒数。关闭行为只由 close/end/切换课堂/回收班级等教师操作触发；到期未到保持 pending，关闭时才转 absent。已发布旧课堂的 attendance_closed_at 不自动清除，历史签到状态不重算。旧无 deadline 的课堂沿用已保存 late_after 作为兼容阈值；新 open 都有 deadline，页面不显示宽限输入。v1 late_after 参数暂留兼容，不影响新签到。

前端依据服务器时间偏移显示倒计时/已超时，不能凭浏览器计时决定服务端资格。轮询不重建学生输入控件。点名候选仍通过 attendance.candidates，未签到视觉状态不改变抽样规则。班级年份学期仅在选座与数据管理显示；日志用稳定 class_id 隔离。

维护者每次发布同步 docs/全部功能与流程.md、docs/功能测试指南.md、docs/images/function-flow.svg 和 README 全功能表；未实现功能保留在路线图。测试用合成数据；新模块浏览器测试真实等待一分钟。数据库升级自动备份，回退先恢复备份，不能直接用旧 EXE 打开 schema 5。


## 1.3.0 覆盖说明

模板识别：core/config.py 对原装 JSON 解析后比较，忽略缩进、键顺序、UTF-8 BOM 和 LF/CRLF 差异；Excel 继续核对旧文件 hash。旧版逐字节 JSON hash 策略已废止，不应恢复。配置更新保留原三份文件在 config/templates/classroom-64-v1。

schema 4：lessons.attendance_deadline、layout_id，attendance_entries.move_reason，以及 seat_change_requests。新课保存布局编号，历史读对应不可变布局。签到 open 操作可带 duration_minutes（1—40，默认 10）；旧开放课 null 截止保持原行为。读状态前 expire_due 持久化已到期的缺勤和结束时间；提交事务内也按服务端时间校验，不依赖浏览器倒计时。

学生 GET / 默认未开放登记时重定向 /attendance。学生 POST /api/v1/student/attendance 新载荷 name、seat_no、lesson_id、move_reason（device_fault|long_term，换座必填）。姓名在同一事务中从课堂快照规范化匹配；未知或同名拒绝。兼容内部 student_id 调用。学生响应无原因、审批信息、请假状态或备注。

教师 POST /api/v1/teacher/seat-changes/<id> 使用 approve 布尔值。审批与 seating.approve_move 在一个事务：验证本节课堂、当前登记、原座位、目标设备和目标空闲，修改该 registration 的 seat_no，不删除身份、不修改历史快照。拒绝不影响本次临时签到；纠正/撤销签到取消待处理申请。结束课堂后申请不可再批准。

seat-map.js 为考勤/点名共用的 ES5 稳定节点渲染器。只有 layout id 变化才重建座位；轮询更新文案/样式。学生输入框和原因选项不参与重建。原座位显示姓名与状态，换座显示实际到场人及原位“已换座”；点名不重复显示已经移走的学生。所有文本 textContent，不执行姓名 HTML。

本节覆盖下面 1.2.0 的 hash 识别、下拉输入和页面操作说明；其余架构继续兼容。现行 UI 术语为“当前座位 / 历史存档”。

## 1.2.0 新模块与数据边界

`attendance` 管理 lessons、attendance_entries、attendance_leave，`rollcall` 管理 rollcall_draws；共用同一 Database，但点名通过 attendance.candidates 获取候选名单，考勤通过 seating.get_current_arrangement(connection) 获取同事务快照，不改座位表。课堂冻结姓名、学生 id、原座位；临时座位与缺勤状态仅存考勤表。详情投影不给学生长期请假、缺勤、IP 或备注。

新页面 /teacher/attendance、/teacher/rollcall、/teacher/data 使用 module.html + modules.js；原选座 app.js 单独维护。学生 /attendance 使用同一模块页面的学生投影。ES5/XHR，每秒短请求刷新，没有外部资源。CSS 统一最低 16px。

教师新增 API：GET/POST /api/v1/teacher/lessons；GET /lessons/current；GET /lessons/<id>；POST /lessons/<id>/open|close|end；PUT /lessons/<id>/students/<sid>（状态或补签座位）；GET /lessons/<id>/export（UTF-8 BOM CSV）；POST/GET /rollcall/<lesson_id>；POST /classes/manage（ids 数组、action delete|restore）；GET /classes?deleted=1。

学生 GET/POST /api/v1/student/attendance，写入 lesson_id、student_id、seat_no；身份必须在快照中。来源 IP 使用 socket，忽略转发头。签到以 BEGIN IMMEDIATE 和座位/IP/会话唯一约束串行校验；重复同身份、同设备、同座位返回成功，不改变首次时间。教师补签可纠正且按当前时刻计算迟到。

课堂同一时刻全局只存在一个未结束记录；开始下一课会关闭上一课。当前资格还须匹配当前班级安排 id 和本机日期，旧班/旧安排/隔日延迟请求拒绝。开始课堂前须结束座位登记。每课名单从当前已就座记录取快照；未就座学生资料不作为应到名单。未发起签到的课堂点名用快照；发起后候选只包含 present/late。

班级删除为回收站：ClassService.set_deleted 标记；路由在同一事务调用 seating.retire_classes、attendance.retire_classes 各自清理活动上下文；没有跨模块修改内部表。恢复不自动重新发布课堂。历史保留可查询，未提供永久清理。

模板升级：resources/templates/classroom-64-v1 保留旧原装模板。只有数据目录三份原装文件 hash 全部匹配时自动备份配置再替换。新 layout id=classroom-64-v2；SeatConfigService 将同一物理机房 v1 历史配置读取映射到 v2；当前登记由座位服务迁移显示布局，存档不动。自定义配置保留原样，由维护者确认后升级。人数格 E18，所有姓名映射由新模板座位数字核对。

以下原有 v1 接口与座位业务继续兼容；布局和模板细节以本节更新为准。

模块化单体应用，Python 3.11 + Flask + Waitress + SQLite；Win10 教师机便携程序，学生页采用 ES5 / XMLHttpRequest，本地资源，无构建前端依赖。

## 模块边界

| 模块 | 负责 | 不负责 |
|---|---|---|
| core | 数据目录、配置、连接、事务、迁移、统一错误 | 班级业务 |
| classes | 班级稳定 id 和名称 | 设备状态 |
| layouts | 不可变布局、跨班级设备状态/备注 | 学生特殊情况 |
| students | 班级内稳定学生 id、规范化姓名、私密备注 | 座位和签到 |
| seating | 当前安排、存档、提交与纠错、当前课堂上下文 | 抽取/签到等未来结果 |
| exports | 调用座位读取接口填原模板 | 直接读取登记 SQL、导出私密备注 |
| web | 同源/本地权限、HTTP 路由、教师/学生页面 | 页面直接操作数据库 |

设备配置写入由 SeatConfigService 封装，学生身份由 StudentService.resolve 处理；登记事务将身份选择与登记一起提交。各服务封装自身 SQL，共用 Database 连接，不为简单 SQL 额外建立空仓储层。

## 当前安排与存档

兼容 v1：数据库继续使用 rounds、round_id，HTTP 保留 /rounds；UI 统一称当前安排 / 历史存档。`archived_at IS NULL` 为当前安排；开始新登记会在同一事务中冻结旧学生备注、存档旧安排、关闭它、创建新的空安排，并选中上课班级。

发起新登记携带 `expected_current_id`（初次 null），与数据库当前安排比较，阻止双击或旧页面意外连续创建存档。已开放同班可直接发起新登记，其他班级开放时拒绝并提示先结束。

`classroom_state.active_class_id` 保存全局上课班级。教师查看班级/存档不会改变它；publish 或发起新登记才改变；服务重启后继续使用。结束登记只关闭学生提交，当前安排继续供学生查看和其他模块使用。

## 共用读取接口

```python
seating.get_current_arrangement()                 # 当前上课班级的当前安排
seating.get_arrangement(class_id)                  # 指定班当前安排
seating.get_arrangement(class_id, round_id)        # 指定只读存档
```

返回：class、round、layout、registrations、count、is_current、seat_configs、active_class_id。无登记时 round 为 null。布局含座位编号、行列、大小组和讲台方向。

每条登记提供 id、student_id、seat_no、name、group、updated_at、source_ip、student_note。设备配置提供 seat_no、disabled、note。**上述是教师内部接口，不能直接作为学生响应。** `active(client_id, source_ip)` 生成学生投影，去除 IP、学生备注、设备备注；只保留设备是否可选与自己的座位。

未来模块按 student_id 区分同名学生，业务开始时保存名单快照；事件和结果另存模块表。不要读 Excel、不要以姓名为主键，也不要通过修改座位表表示出勤。

## 登记与身份规则

- 写操作 `BEGIN IMMEDIATE`，WAL，本机数据库，等待上限 15 秒。
- 唯一约束：每个登记内一个座位、一个客户端会话、一个学生 id、一个 IP 键。设备 IP 限制可配置关闭，但座位和会话限制继续。
- 来源 IP 来自 request.remote_addr，规范化 IPv4 / IPv4-mapped IPv6，不接受客户端或转发头声明。不能防止改 IP；不是实名识别或 MAC 绑定。
- IP 限制范围是登记 id，没有时间过期。教师清除释放占用，下一班或新登记自动重置范围。
- 姓名使用 NFKC、去空白、casefold 规范化比较。学生当前同名拒绝；历史学生名匹配到多个记录也拒绝，引导教师处理。
- 教师编辑默认沿用所选/当前学生 id（纠错姓名），换人应选择已有记录或勾选同名新学生。新建同名记录有不同 id、独立备注。
- 学生备注在 students 表，不随换座消失；存档保存备注快照。未就座学生也可建记录。归档后的旧备注不随资料更新。
- 停用设备保留已登记姓名，但空停用座位不能新登记或补填；已有登记仍可纠错/清除，恢复设备后才可再填。
- submissions 保存幂等收据：同请求重试返回已接收，改变载荷会拒绝；教师清除后旧请求不会复活数据。

## HTTP v1

教师接口全部在 `/api/v1/teacher` 下；要求本机远端地址 + localhost/loopback Host + 管理会话。写接口还要求同源 Origin、JSON、X-CSRF-Token。学生端不允许跨域提交。

| 方法/相对路径 | 数据与行为 |
|---|---|
| `GET /classes` | classes + active_class_id |
| `POST /classes` | name，新建班级 |
| `GET /current` | 共用当前上课安排 |
| `POST /classes/<id>/publish` | 空 JSON，设为当前上课班级 |
| `GET /classes/<id>/rounds` | 当前安排与存档列表 |
| `POST /classes/<id>/rounds` | expected_current_id，发起并存档 |
| `POST /rounds/<id>/close` | 空 JSON，关闭当前登记 |
| `GET /classes/<id>/arrangement` | 可带 round_id 查存档 |
| `PUT /rounds/<id>/seats/<seat>` | name、可选 student_id、force_new、student_note；name 空字符串清除 |
| `PUT /layouts/<id>/seats/<seat>/config` | disabled 布尔值、note，跨班级设备配置 |
| `GET/POST /classes/<id>/students` | 列学生/以 name + note 建未就座记录 |
| `PUT /students/<id>/note` | note，修改该生私密备注 |
| `GET /classes/<id>/export` | 可带 round_id；Excel 下载 |
| `GET /info` | 版本、数据目录、地址、IP 限制设置 |

学生接口：`GET /api/v1/student/state`；`POST /api/v1/student/registrations`，JSON 含 round_id、seat_no、name、request_id。IP 只取服务端 socket 地址。

统一错误：`{"error":{"code":"...","message":"中文提示"}}`，409 业务冲突、403 权限、400 参数、404 不存在、413 请求超过 16 KB、503 数据库暂不可用。姓名最多30字符、班级40、备注1000；备注只显示为文本，私密字段不导出。

## Excel

以 stdlib 修改 Open XML ZIP 中目标工作表的指定单元格，其他成员解压内容保持不变。姓名用 inlineStr，避免公式执行；导出前核对原座位数字与配置。模板映射在 config/excel-template.json，与 layout id 绑定；默认只有 classroom-64-v1。支持其他教室需增加模板版本索引，不覆盖历史布局定义。
