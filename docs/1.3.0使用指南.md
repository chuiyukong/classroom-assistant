# 1.3.0 使用指南

## 升级与模板修复

关闭旧程序，再运行 v1.3.0 文件夹里的 ClassroomAssistant.exe，继续读取原有用户数据目录。数据库升级到 schema 4 前自动备份。

本版修复旧原装模板未更新的问题：Windows JSON 文件的换行与发布版本不同，1.2.0 用原始文件 hash 比较时误判为自定义配置。本版对 JSON 比较解析后的内容，对 Excel 仍做原文件核验。原装模板自动更新为每小组四人、共 16 小组；当前座位保留姓名，历史存档保留旧模板。真正修改过布局或模板的自定义配置不会强制覆盖。

只运行新程序即可完成原装配置修复，不需要删除数据库，也不需要重登记。请通过新版本 EXE 打开教师管理，避免仍连接到旧程序。

## 学生入口

仍然使用原学生网址。只有教师开放座位登记时显示在线选座；未开放时自动进入考勤签到，并隐藏选座入口。已经打开的选座页在登记结束后也会切换到考勤页。

未开展考勤时，考勤页仍显示当前座位布局与姓名。教师新发起座位登记时，考勤页会显示“在线选座”入口；学生可以点击，也可用原网址重新打开。

## 点击座位签到

教师在考勤页开始本节课，设置迟到宽限和签到时长，再点“发起签到”。签到时长默认 10 分钟，可设 1—40 分钟；学生页面显示剩余时间，到时自动停止学生签到。迟到宽限仍独立计算，若宽限大于签到时长，本次学生签到不会被判迟到。

学生点击所坐座位，输入已登记姓名并确认。原座位的大字显示姓名，小字和颜色区分未签到、已签到、已换座；学生不会看到请假、长期请假或私密备注。姓名和原因输入在自动更新期间保留。

临时换座时选择尚无人签到且设备可用的座位，再选择原因：

- 原设备故障：只改变本节课的签到位置，不自动停用设备或改固定座位。
- 申请长期换座：完成本次签到，同时提交申请。教师在考勤页“长期换座申请”中同意后更新当前固定座位；拒绝不会撤销本次临时签到。

长期换座须在本节课堂结束前审批。目标座位如果已有固定登记，系统拒绝覆盖；教师应先在在线选座中核对、调整该座位，再处理申请。原签到快照和旧存档不回写，下一节课按变更后的固定座位生成名单。

同名、误签、设备限制等情况仍到教师端纠正或补签。教师在倒计时结束后、本节课堂结束前仍可补签。

升级前已经开放的旧版签到没有截止时间，不会擅自补设截止；下一次发起的新签到使用倒计时。

## 随机点名

独立页面只保留课堂开始和点名操作，不提供发起/结束签到按钮。未发起考勤使用本节座位名单；已发起考勤只抽已签到学生。动画在真实座位布局上移动高亮，最终框选抽中座位，主结果只显示姓名。每次独立随机，可能重复。

## 文案与界面

标题居中，班级单独展示；去除重复小标题。教师统一称“当前座位”，仅历史存档展示登记日期。选座与考勤的连接状态统一用绿色加粗“状态：已连接”，断线使用红色提示。正文和辅助说明最小 16px。

新版仍需在机房 Win7 浏览器、极域与 Excel/WPS 实际打印环境复测。AI 对话采集与其他路线图功能没有在本版实现。
