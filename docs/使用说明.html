课堂助手 1.1.0 · 座位登记

教师机启动，学生用浏览器填写，按原表导出。无需外网或学生账号。

第一次使用

  1. 将压缩包完整解压到 Windows 10 教师机，双击 ClassroomAssistant.exe。
  2. 启动窗口显示“课堂助手正在运行”，并打开教师管理页面。管理页面没打开时，点击“打开教师管理”。
  3. 添加班级，例如“高一（3）班”，点击“发起新登记”。
  4. 从启动窗口复制学生网址，如 http://192.168.1.10:8765/。多个地址时，先在一台学生机试开，选择可用的那个。
  5. 用极域的打开网页功能，将这个网址发送给全班。

学生网址必须使用教师机的局域网 IP。不要向学生发送 127.0.0.1、localhost 或带 /teacher 的教师管理地址。

当前班级、存档与备注

  • 选择班级只是教师查看。点击“设为当前上课班级”，学生页显示该班当前安排；重启服务后仍保留。
  • “发起新登记”会自动将旧安排转为只读存档。当前安排供以后点名、考勤等功能复用。
  • 点击座位，在“设备配置”勾选停用、填写设备问题后单独保存；这些设置跨班级共用。停用不删除已有姓名。
  • 同一窗口的“学生备注”属于所选学生，仅教师可见，不跟随设备。清除座位不删除学生记录；重新登记时复用无歧义的已有学生记录。
  • 需要处理另一位同名学生时勾选“同名新学生”；如果是已有同名学生，从“已有学生记录”中选择正确编号。
  • “学生备注”按钮可管理全班学生情况，包括创建未就座学生记录。存档保留当时的学生备注。

学生怎么登记

  1. 找到电脑或桌面上的座位号，点击网页上的对应座位。
  2. 填写姓名，核对座位号，点击“确认登记”。看到“登记成功”才表示保存完成。
  3. 已登记座位显示姓名，其他人不能覆盖。填错姓名或座位时，联系教师。

如果显示连接中断，等待恢复后重试。不要仅因为点过按钮就认为已保存。出现同名时请到教师端登记；教师可勾选“同名新学生”，为其建立独立记录。

教师纠错与导出

  • 点击座位，修改姓名后保存。需要换座位时，先清除错误座位，再补填正确座位。
  • 登记完成点击“结束登记”，学生不能再提交；教师仍可修正当前安排。
  • 点击“导出 Excel”，浏览器会下载含姓名、班级、已登记人数的座位表。未登记座位保持空白，课代表栏可在 Excel 中手动填写。
  • 下次上课可以查看该班已有安排；如需重新登记，点击“发起新登记”。旧安排存档保留，可在“当前安排 / 历史存档”中查看和导出。
  • 一个时间只能开放一个班级。更换班级前，请先结束之前班级的登记。

学生打不开网页时

现象检查方法
所有学生都打不开确认启动窗口还在运行；网址是教师机当前局域网 IP，包含正确端口；教师机和学生机网络可互通。
教师机能开，学生机不能开检查 Windows 防火墙。若启动时有防火墙提示，按学校管理要求允许程序在机房网络通信；必要时请机房管理员为教师机配置 TCP 8765 入站规则，来源范围仅限学生子网。无需关闭整个防火墙。
有多个学生网址可能有无线网卡或虚拟网卡。在一台学生机逐个测试，使用机房局域网地址。
Win7 页面显示异常记录 Chrome/Firefox 的具体版本并反馈。页面使用本地资源及较旧的浏览器语法，但仍需以实际浏览器测试为准。
提示已有程序或端口被占用先找已打开的课堂助手窗口；确认没有其他实例。端口冲突时，在数据目录 settings.json 中修改 port，然后重启并重新发送网址。

保存、备份与更新

启动窗口点击“打开数据目录”。默认位置为 %LOCALAPPDATA%\ClassroomAssistant。关闭工具后备份整个目录；不要在运行时只复制数据库文件。更新版本时替换程序即可，原数据独立保留。按本次测试要求，升级到 schema 2 跳过旧测试库备份；后续正式版本升级的备份保存在 backups 文件夹。

同一来源 IP 在本次登记中只能登记一次，切换浏览器不能再次登记。没有十分钟冷却，下一班或新登记立即可以使用同一台电脑。IP 只是设备线索，不能替代身份核对。

机房首次验收清单

  1. 一台 Win7 学生机能打开页面、看到 64 个座位。
  2. 两台学生机同时登记不同座位，教师页能自动更新；两台登记同一座位，只有一台成功。
  3. 断开并恢复学生机网络，页面能重新连接。
  4. 教师结束登记后，学生不能继续提交。
  5. 用极域全班打开，再导出 Excel 检查实际班级与座位。
教师机程序适用 Windows 10/11 x64；学生机使用已有 Chrome 或 Firefox。机房实际联机验证由教师现场完成。
