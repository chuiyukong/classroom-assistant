# 功能测试指南 · 1.4.0

用于机房验收。请逐项填写“通过/失败/未测”，不要凭页面能打开就判为通过。自动化测试不能代替 Win7/极域和打印实测。

## 准备

用独立测试数据目录启动（启动参数 `--data-dir` 指向空测试文件夹），避免在正式班级制造测试记录。准备教师机、两台不同 IP 学生机 A/B；A 安装两种浏览器。记录系统、浏览器版本、屏幕分辨率、程序版本、测试时间及网络是否有代理。姓名使用“测试甲/乙/丙”，备注使用“测试备注”。

先建 2026 上学期“测试班”，准备三位学生的固定座位 1/2/3，64 号留空；完成登记后结束登记。以下需清空或新开课堂的操作仅对测试班进行。

## 十分钟核心验收

| 编号 | 操作 | 应看到的结果 | 实测 |
|---|---|---|---|
| C01 | 新建同名班，分别选不同年份/学期 | 可以共存；相同年份学期同名拒绝 | 待填 |
| C02 | 设为当前上课班级，开放座位登记 | 教师和学生出现深绿“座位登记开放中”，学生选座入口出现 | 待填 |
| C03 | A 登记 1 号；A 换浏览器登记 2 号 | 第二次被本机限制拦截 | 待填 |
| C04 | B 用 A 的名字登记空座 | 同名提示联系教师，不覆盖已有记录 | 待填 |
| C05 | 完成三人固定名单，结束登记 | 学生默认签到页，选座入口隐藏，仍能看名单 | 待填 |
| C06 | 开始本节课堂，签到时长选 1 分钟，发起 | 教师/学生绿块倒计时，未出现迟到宽限输入 | 待填 |
| C07 | 截止前让甲在原位签到 | 正常已到，实到增加，座位变绿 | 待填 |
| C08 | 等完整一分钟，乙输入框保持打开 | 倒计时变橙色“已超时”，表单姓名保留，仍能提交 | 待填 |
| C09 | 超时约 20 秒让乙签到 | 自动迟到，迟到约 20 秒（教师列表按分钟向上显示），没有自动结束签到 | 待填 |
| C10 | 教师结束签到；丙再提交 | 丙被拒绝，未签到变缺勤；教师仍可补签 | 待填 |
| C11 | 进入随机点名 | 使用本节已到名单，无须再开始课堂；丙不被抽中且未到座位有色彩提示 | 待填 |
| C12 | 1366×768 浏览器，缩放 100% | 点名全部 64 座及讲台可见，无须滚动看全座位图 | 待填 |

| F12 | 申请换到乙固定座位但乙未签到 | 可临时签；长期审批拒绝覆盖乙，教师核对调整 | 待填 |
| F13 | 教师拒绝长期申请 | 临时签到保留，固定座位不变 | 待填 |

| F16 | 截止前后重启教师服务 | 原截止时间和签到保留；超时后仍可迟到签到，不重置倒计时 | 待填 |
| F17 | 手动结束签到后重启 | 不重新开放；学生不能签到 | 待填 |
| F18 | 教师补签/改请假/撤销签到 | 人数与状态同步；结束课堂后不可改 | 待填 |
| F19 | 未发起签到直接随机点名 | 从固定名单抽；没有自动把学生判为缺勤 | 待填 |
| F20 | 已发起签到但无人签到时点名 | 提示无可点名单，不抽缺勤者 | 待填 |
| F21 | 换座后点名抽中甲 | 高亮实际签到座位，结果只有姓名，原位不重复候选 | 待填 |
| F22 | 班级日期查询、导出 CSV | 人员、状态、时间与所选课堂一致，无其他班混入 | 待填 |
| F23 | 数据管理年份/学期筛选、全选删除、恢复 | 只操作当前筛选所选班，历史保留，设备不受影响 | 待填 |
| F24 | 新旧 Excel 模板导出 | 核对 64 姓名格、班级、人数、空格、其他表、打印预览；原文件不被覆盖 | 待填 |
| F25 | 学生从局域网访问教师页/接口 | 拒绝，无教师权限及私密备注泄露 | 待填 |
| F26 | 极域统一打开 64 台学生机同时登记/签到 | 无重复覆盖、人数正确、浏览器输入稳定；记录真实 IP 和浏览器版本 | 待填 |

## 自动化验证入口

维护者使用 pytest、check_browser.py、check_modules_browser.py 和 check_package.py，全部临时数据。模块浏览器测试真实等待一分钟，验证从正常倒计时变迟到且仍可提交、再验证教师关闭禁止签到；后端另测截止前一秒、精确截止、超时 125 秒、重试、重启和学期迁移。
