# 功能测试指南 · 1.9.0

## 本次优先：全班一整节课

1. 新版启动后等约5秒，确认窗口“服务正常”。先教师127.0.0.1和一台学生机访问`/health`，再极域打开全班，避免重复打开多份页面。
2. 至少50名测试学生（或现场正式学生正常操作）完成登记、签到；保持60多台浏览器40分钟，教师每隔几分钟切换选座、考勤、点名、数据页。记录人数、时间、是否卡顿，不将姓名写入故障报告。
3. 发生转圈先按[排查报告](服务长时间加载排查报告.md)比较两端health、保存日志；不连续刷新、不删除数据。恢复后确认已确认成功的登记与签到仍在。
4. 检查学生选座、考勤：讲台在上，最靠近讲台一排从左到右为57/49、41/33、25/17、9/1；教师图仍是原方向。点击后提交的座位号应和按钮一致。
5. 停用一个测试空位，两端只显示“设备停用”，学生不能选；有登记信息的设备停用也保持标识。恢复设备后名单仍在。
6. 班级数据页核对当前座位人数，修改班级名称和毕业届数，刷新/重启后保留；历史课堂仍显示当时的名称与届数。人数不是累积历史登记次数。

本机已做64隔离Chromium页面611秒持续验证，并非64台Win7，也未替代本项40分钟现场验收。

用于机房验收。请逐项填写“通过/失败/未测”，不要凭页面能打开就判为通过。自动化测试不能代替 Win7/极域和打印实测。

## 准备

用独立测试数据目录启动（启动参数 `--data-dir` 指向空测试文件夹），避免在正式班级制造测试记录。准备教师机、两台不同 IP 学生机 A/B；A 安装两种浏览器。记录系统、浏览器版本、屏幕分辨率、程序版本、测试时间及网络是否有代理。姓名使用“测试甲/乙/丙”，备注使用“测试备注”。

先建 2026 上学期“测试班”，准备至少 50 位虚构学生，固定座位 1—50（1/2/3 用于以下操作），64 号留空；完成登记后结束登记。以下需清空或新开课堂的操作仅对测试班进行。
