# 课堂助手 v1.2.0

新增独立的考勤签到、随机点名和班级数据管理页面，在线选座统一最小 16px 字号，大标题显示当前上课班级。采用 2026-09-07 新版 64 座模板，保留历史模板导出。

- 考勤：每节课名单快照、临时换座、每机/每生/每座防重复、迟到宽限、教师补签、长期请假延续、实时汇总、日期查询与 CSV 日志。
- 点名：未签到用座位名单，已发起签到用到场名单，动画展示，服务端保存结果。
- 班级：单个/批量移入回收站与恢复，保留历史和设备状态。
- AI 对话采集已完成方案，尚未实现；本版不调用付费 API。

关闭旧程序后解压 Win10-x64 包并运行 EXE。schema 3 升级前自动备份；本次不再跳过备份。原装模板自动升级，自定义 config 不强制覆盖。操作细节见 docs/1.2.0使用指南.md。

48 项 pytest、两套浏览器流程与实际 EXE 检查通过。自动测试与浏览器验证见 docs/验收记录.md。用户反馈旧版机房连接正常；本版新增功能、Win7 浏览器和新模板实际打印仍需现场复测。仓库及附件保持私有。
