# 课堂助手 v1.3.0

- 修复原装模板因 Windows JSON 换行差异未升级的问题；保留自定义配置、当前姓名与历史模板。
- 学生未开放登记时进入考勤页；选座入口只在开放登记时出现。
- 座位图点击签到、大字输入姓名，修复自动刷新重建下拉框打断操作的问题。
- 签到倒计时默认 10 分钟，可设 1—40 分钟；到时由服务端拒绝签到。
- 临时换座记录原因，长期换座支持教师批准/拒绝。批准更新当前座位，目标已有固定登记时不覆盖。
- 点名页面移除考勤操作，使用教室布局动画与座位高亮，结果只显示姓名。
- 统一居中标题、班级排版、连接状态颜色和“当前座位”文案。

关闭旧程序后使用本包 EXE；schema 4 升级前自动备份，原装模板无需删除数据或重登记即可更新。详细说明见 docs/1.3.0使用指南.md。
