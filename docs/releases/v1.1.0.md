# 课堂助手 v1.1.0

局域网计算机教室座位登记工具。教师机启动服务，学生用浏览器登记，教师按原 Excel 模板导出。

## 下载与运行

下载并解压 **ClassroomAssistant-v1.1.0-Win10-x64.zip**，在 Windows 10/11 x64 教师机双击 ClassroomAssistant.exe。无需另装 Python 或 Office。源码与维护文档在 Source.zip，或直接克隆仓库。

## 本版本

- 按本次登记的来源 IP 与浏览器会话防重复，换浏览器不能再次占座；新登记立即重新计数。
- 学生同名提交引导教师处理，教师可创建独立同名记录。
- 当前安排与只读存档，发起新登记自动存档；明确当前上课班级。
- 跨班级设备停用与设备备注，学生备注绑定独立学生记录，仅教师可见。
- 保留原模板 Excel 布局，附项目状态、路线图、版本与维护文档。

## 验证及边界

39 项后端测试、Chromium 流程、64 HTTP 客户端模拟独立 IP 并发、独立 EXE 检查已通过。Win7 浏览器具体版本、极域全班联机和防火墙仍需机房现场确认。

本次为测试阶段版本。目标 schema 2 的旧测试库升级跳过自动备份；未来迁移保留常规备份机制。IP 不是学生身份，改 IP 或共享代理影响限制效果。

噪声检测、考勤、随机点名及小游戏只在路线图中，尚未实现。
