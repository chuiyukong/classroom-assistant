# ClassroomAssistant v1.4.0

# 版本变更记录

## 1.4.0 — 2026-09-08

- 签到取消前端迟到宽限；截止时刻起仍接受签到并计为迟到，倒计时改为已超时时长。教师手动结束签到/课堂后才拒绝学生提交，未签到转缺勤。旧已关闭课堂不自动重开。
- 教师/学生使用一致的深绿开放、橙色迟到签到、灰色关闭状态块；收紧 64 座图和组间距，点名在 1366×768 下展示完整座位与讲台；未签到座位增加浅红提示。
- “开始新的一节课”改为“开始本节课堂”，明确考勤/点名共用一次课堂快照，不重复开始。
- 新建班级独立选择年份、上/下学期；同名班可按学期区分，数据管理增加筛选。其他课堂页仅显示班级名；旧班保留并标为未设置学期。
- schema 5 重建班级唯一约束为名称+年份+学期，保留编号及全部关联；自动备份，不修改已发布迁移。
- 新增完整功能流程图、全部功能说明、核心与完整人工验收指南；README 收录总览，每次发布同步维护。
- 验证：58 项 pytest、原选座浏览器检查、真实一分钟签到跨截止及手动关闭检查通过；实际 EXE 检查见验收记录。Win7/极域与 Excel/WPS 新模板打印仍待现场复测。


操作方法见 docs/全部功能与流程.md，测试步骤见 docs/功能测试指南.md。更新前关闭旧程序，解压新包运行；数据独立保存，schema 5 升级自动备份。仓库及发布资产保持私有。
