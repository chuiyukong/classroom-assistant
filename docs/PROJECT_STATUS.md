## 数据和模块边界

- 固定座位不依赖考勤；每节课创建独立名单快照，class_id/lesson_id/student_id是后续数据关联键。
- 设备配置和备注跨班级；学生备注私密，学生界面仅展示考勤状态，不展示IP或纠正记录。
- 日志页只读，不在历史图修改数据；教师在本节考勤座位弹窗纠正，必须先处理再下课。
- 新点名不创建课堂；无当前考勤读固定座位，有当前考勤读到场。每班保存最后手动范围，不存点名结果。
- AI、噪声、游戏未开工；教学日志只有占位入口。未来模块通过公共服务关联本节课堂。
- 用户明确要求这次清除旧测试库，但删除数据库及备份文件被工具自动审批拦截（blocked by policy），未清空。之后实际试运行的数据必须保留；禁止加入自动清库，正式升级仍备份。
