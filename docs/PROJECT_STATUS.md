# 项目当前状态与接手指南

更新：2026-09-08。当前源码 **1.3.0**，数据库 **schema 4**。用户反馈旧版已在机房连接正常；新版功能仍待现场复测。仓库 chuiyukong/classroom-assistant 必须保持私有。

## 1.3.0 本次修复与决定

- 学生默认考勤页；教师开放登记时才出现选座入口。学生点击真实座位图并输入姓名签到，不使用自动刷新的下拉框。
- 考勤、点名共用 seat-map.js，布局来自服务端；输入框不随轮询重建。点名只保留本节课堂开始和点名，不包含签到操作。
- 截止时间由服务端保存，默认 10 分钟，可设 1—40；到时拒绝学生提交，状态读取时将到期未签到持久化为缺勤。旧版已开放且无截止时间的课堂保留教师控制，不追设时间。
- 原装配置识别改为 JSON 内容比较 + Excel 文件校验，修复 Windows CRLF 未升级；自定义文件继续保留。
- 长期换座申请只在本节结束前审批；批准通过 seating.approve_move 更新固定座位，目标已有登记或申请来源座位已变更时拒绝。学生的设备故障理由不自动停用设备。
- 文案按用户新要求统一“当前座位”，存储 round/API 名称不变。标题居中、班级独立、连接状态同色加粗。

## 已实现

- 在线选座：64 座、新模板每组四人、IP/会话防重复、重名教师处理、当前座位与历史存档、设备配置及学生私密备注。
- 界面：独立功能导航，最小 16px，标题突出当前上课班级。
- 考勤：每节课堂名单快照、临时换座、并发冲突保护、迟到宽限、长期请假延续与签到解除、教师纠正、日期查询和 CSV 日志。
- 随机点名：未发起签到用课堂座位快照，已发起签到只用到场名单，服务端随机和结果记录。
- 班级数据：单个/批量移入回收站和恢复；删除关闭该班登记和课堂，保留历史、设备配置。
- 新模板：原装配置自动升级，当前座位保持姓名并切换 v2 分组，旧存档使用 v1 模板；自定义配置不覆盖。

## 已确定的规则

每节课点击“开始新的一节课”；发起签到是独立操作，不清空座位。课堂名单取开始时当前座位中的学生，不包含未就座学生资料。历史名单不会因改名/换座而变化。结束签到后教师仍可纠正，结束本节课后只读。长期请假是独立考勤标记，不从学生自由备注推断。

迟到从签到发起时间加宽限计算，默认宽限 5 分钟；应到包含请假，实到包含迟到。未发起签到的课堂不自动认定缺勤。同 IP、学生、座位在本节签到中各只允许一条；IP 不是身份验证，仍无法防止冒选其他人的姓名。重名需教师补签。

当前班级切换或座位登记更新后旧课堂不能继续提交；隔天旧课堂不再作为当前课堂，必须开始新课。每次点名独立随机，可能重复。历史考勤保留结束前最终状态，没有完整的每次纠正审计链。
