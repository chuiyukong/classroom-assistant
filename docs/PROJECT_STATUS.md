# 项目状态与接手入口

更新：2026-09-08。当前源码 **1.5.0**，数据库 **schema 5（本次无迁移）**，显示名称智慧课堂综合平台。仓库必须私有。

## 当前实现

选座、设备配置、学生备注、学期班级管理、考勤与审批、独立点名均已实现。完整行为只在 README 维护，技术规则只在开发维护维护，版本历史见 CHANGELOG。

1.5.0 重点：统一 UI 和品牌，年份前后十年，移除独立备注按钮；自动切换学生选座入口；已签到不显示倒计时；学生可见长期请假状态但看不到私密原因；座位弹窗纠正/补签，审批日志右侧；无考勤点名无需课堂，当前有考勤仅抽到场，新点名不保存，多人避免紧邻重复。

## 依赖边界

- 固定座位不依赖考勤，通常每学期首次登记后长期复用。
- 签到、长期请假延续、临时座位、长期审批、考勤日志依赖本节课堂快照。
- 点名不创建课堂：没有当前考勤用固定座位，已发起本节考勤用到场名单；结束签到仍关联，结束课堂后恢复固定名单。
- 未来 AI 学习拟依赖课堂与签到身份，尚未开工；不因点名独立而改掉身份隔离方案。
