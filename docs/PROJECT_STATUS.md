## 已确认的产品决定

- 不是“每隔十分钟可以再登记”：同一电脑在同一次登记里持续受限，教师开新登记后立即解除上一份登记的限制。
- 上课可以沿用当前座位安排，无需每节课重新登记。考勤将是独立的签到记录，不能清空座位安排。
- 班级选择只是教师查看；必须点击“设为当前上课班级”或发起该班登记，才改变所有学生看到的内容。
- 设备状态跨班级共享；学生特殊情况只给教师查看，采用备注，不把自由文本自动解释为免考勤。
- 新登记保留学生记录和备注，不自动把旧姓名填回座位；学生重新登记时仅在姓名无歧义时复用记录。
- 旧版本无法回溯来源 IP。迁移不捏造 IP、不删除历史重名，不对历史同名学生推断身份。
- 当前用户已说明旧库为测试库，无需备份。仅本次 schema 2 升级跳过备份，后续恢复常规机制。

## 尚未实现 / 已知限制

- 噪声检测、考勤、随机点名、小游戏均只列入 ROADMAP，未加入依赖或空功能入口。
- IP 防重复适合学生机直连教师机。切换网络地址可绕过；共享代理/NAT 出口会误拦，不是实名验证。以后可做受控机号绑定，不采用浏览器指纹冒充可靠身份。
- 当前学生身份是班级内的本地记录，没有学号、名单导入或跨班转学关联。重名已有多个记录时需教师选择。
- 设备设置按布局 id + 座位号保存，目前只有一个固定教室布局。新增教室时应增加教室实体和模板版本映射。
- 历史存档的学生备注为快照；设备状态是实时配置，并非历史故障快照。
- Excel 不导出私密备注，不加入考勤表；超长姓名仍受原模板列宽限制。
- 实际 Win7 Chrome/Firefox 版本、极域和防火墙需要现场确认；未采集麦克风数据。

## 如何继续

先读项目根目录 AGENTS.md、CHANGELOG、开发说明和 MAINTENANCE。实施新功能前确认用户具体授权，再从 ROADMAP 拿取候选需求。发布时更新版本文件和文档，跑测试、打包、做独立 EXE 检查；现场未验证项继续保留。

验证的具体命令和结果在 `验收记录.md`。此文档与源代码一同打包，不依赖当前聊天、账号、AI 模型或个人记忆。
