# 项目当前状态与接手指南

更新：2026-09-07。当前源码 **1.2.0**，数据库 **schema 3**。用户反馈旧版已在机房连接正常；新版功能仍待现场复测。仓库 chuiyukong/classroom-assistant 必须保持私有。

## 已实现

- 在线选座：64 座、新模板每组四人、IP/会话防重复、重名教师处理、当前安排与历史存档、设备配置及学生私密备注。
- 界面：独立功能导航，最小 16px，标题突出当前上课班级。
- 考勤：每节课堂名单快照、临时换座、并发冲突保护、迟到宽限、长期请假延续与签到解除、教师纠正、日期查询和 CSV 日志。
- 随机点名：未发起签到用课堂座位快照，已发起签到只用到场名单，服务端随机和结果记录。
- 班级数据：单个/批量移入回收站和恢复；删除关闭该班登记和课堂，保留历史、设备配置。
- 新模板：原装配置自动升级，当前安排保持姓名并切换 v2 分组，旧存档使用 v1 模板；自定义配置不覆盖。

## 已确定的规则

每节课点击“开始新的一节课”；发起签到是独立操作，不清空座位。课堂名单取开始时当前安排中的学生，不包含未就座学生资料。历史名单不会因改名/换座而变化。结束签到后教师仍可纠正，结束本节课后只读。长期请假是独立考勤标记，不从学生自由备注推断。

迟到从签到发起时间加宽限计算，默认宽限 5 分钟；应到包含请假，实到包含迟到。未发起签到的课堂不自动认定缺勤。同 IP、学生、座位在本节签到中各只允许一条；IP 不是身份验证，仍无法防止冒选其他人的姓名。重名需教师补签。

当前班级切换或座位登记更新后旧课堂不能继续提交；隔天旧课堂不再作为当前课堂，必须开始新课。每次点名独立随机，可能重复。历史考勤保留结束前最终状态，没有完整的每次纠正审计链。
